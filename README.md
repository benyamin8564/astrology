# Astro Research Analyzer

نسخه ارتقایافته پژوهشی برای نمودار تولد، آسترولوژی غربی/سیدریال، نامورولوژی و زودیاک چینی.

## امکانات فعلی
- نمودار دایره‌ای Natal Chart داخل APK
- جدول سیارات، درجه، نشانه، خانه و موضوع خانه
- ASC و MC
- جنبه‌های اصلی با orb
- Tropical و Sidereal/Lahiri تقریبی در رابط
- Whole Sign و Equal houses
- تحلیل نمادین خانه‌های رابطه، شغل، مالی و سلامت
- نامورولوژی: Life Path، Expression، Soul Urge، Personality، Birthday، Personal Year
- زودیاک چینی و سازگاری سنتی سال‌ها
- پشتیبانی از اعداد فارسی/عربی در تاریخ و ساعت

## محدودیت دقت
موتور نجومی این پروژه هنوز یک اپمریس حرفه‌ای مانند Swiss Ephemeris نیست. بنابراین برای «دقت نجومی درجه‌به‌درجه» و استفاده پژوهشی/انتشاراتی باید موتور اپمریس معتبر با مجوز مناسب یکپارچه شود. همچنین پیش‌بینی قطعی بیماری، ازدواج یا سود سرمایه‌گذاری از نظر علمی قابل تضمین نیست.
